# PlacementPro – Job & Placement Tracker

A portfolio-ready full-stack application for students to track job applications, interview stages, skills, and placement progress.

## Tech Stack
- Frontend: React + Vite
- Backend: Spring Boot 3
- Database: H2 by default (easy demo), MySQL-ready configuration
- API: REST

## Features
- Add, update and delete job applications
- Track application status
- Dashboard with application statistics
- Responsive student-friendly UI
- REST API with Spring Boot
- Clean Git/GitHub-ready project structure

## Run Backend
```bash
cd backend
mvn spring-boot:run
```
Backend: http://localhost:8080

## Run Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend: http://localhost:5173
